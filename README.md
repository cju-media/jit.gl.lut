# jit.gl.lut 

<img width="909" height="311" alt="LUT in Action" src="https://github.com/user-attachments/assets/69a53d11-6621-4941-93b3-d1cb7cf2c9a6" />

haldCLUT processing via a shader file in jit.gl.slab. The abstraction (jit.gl.lut) simplifies usage. 

## Install Instructions
- Download the whole folder and drop it in your Max file path. Calling jit.gl.lut in any max patch will load the abstraction.
- Use the help file to see how to use the object. Includes a script to simply convert a .cube to a haldCLUT.

Find more haldCLUTs [here](https://github.com/cedeber/hald-clut/tree/master/HaldCLUT)
